ATCP Song Skills Matrix

The ATCP Song Skills is an internal Accenture Song tracking document used specifically for Song Bench resources to capture, standardize, and maintain visibility of individual technical and functional skills.

It serves as single source of truth for capability profiling within ATCP Song Bench.

✓ Task Completed
Step 1

Open the ATCP Song Skills Matrix File.xslx and select the current FY sheet.

ATCP Song Bench Skills Matrix

Step 2

Complete your resource details from columns A to CF.

Your primary skill is already pre-populated.

Step 3

For each listed skill, enter your experience in months in corresponding column.

Step 4

If you have skills that are not listed, add them to the Oher Skills column using this format: Skill Name - X months.
